# Adaptive Smart Classroom

Adaptive Smart Classroom is an interactive web-based learning system that adapts the learning experience based on user preferences and supports multimodal interaction.

## Features

* 🎤 **Voice Input** — Users can select learning preferences using voice commands.
* ✋ **Hand Gesture Interaction** — Users can control classroom actions using hand gestures.
* 🖱️ **Mouse/Text Interaction** — Users can interact with the classroom using buttons and dropdown menus.
* 🧠 **Adaptive Learning Plan** — The system generates a learning plan based on subject, learning level, learning mode, and available time.
* 📚 **Personalized Topics** — Recommended topics change according to the selected learning level and subject.

## Technologies Used

* HTML
* CSS
* JavaScript
* MediaPipe Hands
* Web Speech API

## Supported Interactions

| Interaction    | Action                                       |
| -------------- | -------------------------------------------- |
| Mouse / Text   | Select preferences and control the classroom |
| Voice          | Set learning preferences                     |
| ☝️ One Finger  | Next Topic                                   |
| ✌️ Two Fingers | Previous Topic                               |
| 👍 Thumbs Up   | Confirm Selection                            |
| 🖐️ Open Palm  | Pause Classroom                              |

## Purpose

The project demonstrates how **multimodal interaction** can be used to create a more adaptive and interactive learning environment.
